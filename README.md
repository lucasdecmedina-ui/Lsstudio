# LS Studio Santos

Site institucional responsivo do LS Studio Santos, com treinamento integrado, LS Running, horários, convênios, Instagram, WhatsApp e localização.

## Visualização local

Execute `ABRIR-SITE.cmd` no Windows com Python instalado, ou rode:

```bash
python iniciar-preview.py
```

Acesse http://localhost:8793/. Mantenha a janela aberta durante a visualização.

## Hospedagem

O projeto é estático e não precisa de instalação ou build. Publique `index.html`, `styles.css`, `script.js` e a pasta `assets` na raiz do provedor. Para GitHub Pages, selecione a branch `main` e a pasta `/ (root)`.

## Estrutura

- `index.html`: conteúdo e estrutura.
- `styles.css`: identidade visual, responsividade e animações.
- `script.js`: menu, animações e links de WhatsApp.
- `assets/`: logos e fotos de campanha.

As fotos são imagens ilustrativas geradas. Os banners fornecidos foram usados somente como fonte de informações e não são exibidos. As logos LS Studio e LS Running foram preservadas.
